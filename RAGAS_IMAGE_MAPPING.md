# Ragas Product Crop Integration

All 25 cropped Ragas sparklers images from the supplied album are included under `public/products/ragas/` and are now wired into the runtime image resolver.

The mapping uses the existing 25 sparklers product IDs. Where the current product name does not contain the source album's exact size/colour label, the assignment is made by the closest catalogue size/variant so every supplied crop is used. No product names or prices were changed.
